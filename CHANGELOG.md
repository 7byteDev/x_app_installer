# Changelog

## 1.1.0 — 2026-10-20

- Added local Git version control and release tags.
- Centralized the application version in Version.props.
- Display the version in the app and show build details in Settings.
- Build versioned release folders and ZIPs with SHA-256 checksums and a release manifest.
- Added a version increment script and documented the release workflow.

## 1.0.0 — 2026-10-20

- Saved the existing 29-app installer as the initial Git snapshot.
- Includes application discovery, dependency checks, verified downloads, activity logs and vendor icons.
